# Практические работы по Unix

Реализация системных утилит на C. Всё лежит в папке [lab1](lab1/), собирается одним Makefile.

| Утилита | Работа | Что умеет |
|---|---|---|
| `mycat` | 1 | аналог `cat`, флаги `-n`, `-b`, `-E` и их сочетания |
| `mygrep` | 1 | аналог `grep`, регулярные выражения, работа в конвейере |
| `myls` | 2 | аналог `ls`, флаги `-l`, `-a`, выравненная таблица, цвета по типу файла |
| `mychmod` | 3 | аналог `chmod`, восьмеричный (`766`) и символьный (`ug+rw`) режим |

## Сборка

```sh
cd lab1
make
```

## Примеры запуска

```sh
./mycat -n file.txt
./mycat -b -E file.txt
./mycat file.txt | ./mygrep pattern
ls -l | ./mygrep pattern
./myls -la ..
./mychmod 766 file.txt
./mychmod ug+rw file.txt
```

## Проверка

```sh
make test
```

Скрипт собирает утилиты и сравнивает их вывод с системными `cat`, `grep`, `ls` и `chmod`
на одних и тех же данных — расхождение подсвечивается как `FAIL`.
